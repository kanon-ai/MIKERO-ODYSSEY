MIKERO-ODYSSEY MSX2+ / Z80 prototype v0.1.4
2026-10-11

専用フォルダーで開発したMSX2+向け試作です。既存MSX1版・GitHub公開版は変更していません。

必要環境
MSX2+ (V9958)、Z80、RAM64KB以上、VRAM128KB、ASCII16 512KB ROM。
音楽にはMSX-MUSIC (YM2413/OPLL、内蔵または対応拡張)が必要です。
MSX2+の全機種がOPLLを内蔵しているわけではありません。
R800は使用していません。MSX2/V9938・初代MSX向けではありません。

起動
配布フォルダーのSTART.cmdを実行します。外部のopenMSXとC-BIOSが必要です。
別のopenMSXを使う場合はOPENMSX_EXEとOPENMSX_SYSTEM_DATAを指定できます。
blueMSXなどではMSX2+またはturbo RのZ80設定でROMをASCII16として読み込みます。
blueMSXでのこの移植版の検証、実機検証は未実施です。
旧版のセーブステートを復元せず、新規起動してください。

操作
左右: タイトルでEASY / NORMAL / HARDを選択。SPACE: 開始。
方向キー: 移動・肉球。SPACE: 待機。Z: 回復。
Keeper・ショップは隣から方向入力。結果画面はSPACEでNEW GAME、Xでタイトルへ。

変更
SCREEN 5の新しい16色アート。床は落ち着いたミント色で、直前の試作からRGBを
5,6,5 → 4,5,4 (各0..7)へ下げました。未探索部分は暗闇として区別しています。視野外の既知の壁は暗いブロックで表示します。
生物やアイテムは輪郭を付け、床全体の点滅や騒がしい柄は使っていません。
8種類の壁パレット、ミケロと生物・Keeper等のアニメーション。
V9958の横・縦スクロールレジスタを使用。1移動16pxを2pxずつ8回に分割。
ミケロはスプライト、画面下の情報欄はライン割り込みで固定しています。
OPLLの主旋律・和音・低音3声。行動時に64行動単位の音楽が進み、停止後に消音。
効果音はPSG。猫・ウサギ・肉球で送り返す世界観、難易度、補給・戦闘ルールは維持。

検証
openMSX / C-BIOS / Z80 / V9958 / OPLLで50Hzと60Hzを確認。
短押し1マス、縦横スクロールの段階、回復、HARDの鍵と階段、救出・再開・門閉鎖を検証。
OPLLの3声キーON、停止後キーOFFと音量ミュートを確認。VRAMタイミング違反0件。
ゲーム処理12関数が基準版ソースと一致、120地形のROMバンクも一致しています。
機能テストは明示的なRAMテスト配置を使用しています。プレイGIF/音声は通常入力だけの収録です。
長押し移動は今回の開けた通路テストで約0.31秒/マス(60Hz)、約0.35秒/マス(50Hz)。
スクロールは滑らかですが、MSX1版と同じ移動速度にはまだ達していません。
描画前処理の最適化余地があり、現段階ではR800必須とはしていません。
30階の連続プレイ全体、実機、各社純正BIOSは未検証です。正式リリースではありません。

ビルド
Python 3 + Pillow、SDCC Z80を使用。SDCC_BINにbinディレクトリを設定し、
python work/source/build.py を実行します。
BIOS、エミュレータ本体は同梱していません。
