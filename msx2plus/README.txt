検証
上下左右×50/60Hzで、隣接した敵の追跡と描画更新の順序を確認。
旧版では旧主人公位置への先行描画を再現、新版では0件。
表示タイルとゲーム画面の一致、スクロールなしの攻撃も確認。
50/60Hzの36項目: 短押し1マス、2段階のカメラ位置、縦横移動、OPLL3声と消音、
回復、HARDの鍵と階段、階移動、救出、再開、門閉鎖、VRAMタイミング違反0件。
情報パネル・救出後の下部消去・タイトル復帰も確認。検証配置はRAMへ明示的に配置しています。
実機・blueMSX・30階連続プレイ全体は未検証。

必要環境
MSX2+ / V9958、Z80、RAM 64KB以上、VRAM128KB、512KB ASCII16 ROM。
音楽はMSX-MUSIC (YM2413/OPLL)が必要。R800未使用。初代MSX/MSX2向けではありません。

起動
展開してSTART.cmd。外部openMSX・C-BIOSが必要です。本体やBIOSは同梱していません。
OPENMSX_EXE / OPENMSX_SYSTEM_DATAで別のopenMSXを指定できます。
別の対応エミュレータではROMをASCII16で読み込み、旧版のセーブステートは使わず新規起動してください。

操作
タイトル左右: EASY/NORMAL/HARD、SPACE:開始。
矢印:移動・肉球、SPACE:待機、Z:回復。Keeper・ショップは隣から方向入力。
結果画面SPACE:NEW GAME、X:タイトル。

ビルド
Python3 + Pillow / SDCC Z80。必要に応じてSDCC_BINを設定し、python work/source/build.py。
MSX2+ v0.1.7 公開試作版です。

救出画面の追加修正
ミケロ・Keeper・担架の救出用タイルだけ、背景の床色を黒へ変更。
通常フロアのタイル・スプライト・パレット・地形バンクは直前の高速修正版と同一です。
救出中のVRAMで床色インデックス1が0画素、救出画像と結果画面への遷移を確認。
最終ROMの移動速度も50/60Hzで再測定し、約0.200秒を維持しています。
pre-rescue-で始まる検証記録は救出背景の追加修正前のものです。
速度と救出背景の記録は、この最終ROMのハッシュで確認しています。

2026-10-11 音量調整版へ差し替え
BGM・PSG効果音を各2段階増加。openMSXの同一設定でBGM・回復音とも約6dB増加。
録音上のクリッピングなし、停止時の消音を確認。曲・音色・発音タイミングは維持。
volume-verification.jsonが今回のROMの検証です。他の検証記録は音量調整前のハッシュを保持します。
