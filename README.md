# MIKERO-ODYSSEY

A turn-based cat dungeon adventure for the original MSX: 15 floors in EASY, 30 in NORMAL.

猫のミケロで、EASYは地下15階、NORMALは地下30階に挑む、スコアトライアル型のローグゲームです。限られた視界を頼りに道を探し、迷い込んだ生物を肉球でポンと元の世界へ送り返しながら、どこまで潜れるかに挑戦します。

現在の公開版は **v1.6.1-test**。高速化、EASY／NORMALの難易度選択、異世界の門を閉じるエンディングを追加し、MSXのキークリック音を無効にしました。

## 動作の様子

![最新版の連続移動と肉球による帰還](docs/gameplay.gif)

v1.6.1-testをopenMSXのMSX1・RAM32KB環境で動かした、約14秒の映像です。ミケロを中心にした連続移動と、肉球で生物を元の世界へ送り返す様子を収録しています。GIFの再生時間は実際のエミュレーション時間に合わせています。GIFは無音です。

## どんなゲーム？

- **行動するたびに時間が進むローグゲーム。** 移動・攻撃・待機・回復薬で1ターン進みます。入力を待つ間、敵の行動と空腹の進行は止まります。
- **ミケロを中心に周囲がスクロール。** 1マスは16×16ドット。移動表示を8ドットずつ2回に分け、15×9マスの範囲を見渡せます。
- **階段の方角が分かる三角マーカー。** 未探索でも右上に大まかな方向を表示します。壁を避けた道順ではないので、通路を探しながら進みます。
- **階ごとに変わる色と雰囲気。** 黒い床を基調に、壁やキャラクターが色鮮やかにアニメーションします。8種類のテーマが迷宮を彩ります。
- **行動に合わせて進む2声の音楽。** ひと区切りずつ鳴り、手を止めると短い余韻のあと静かになります。64行動分の旋律を巡ります。

選んだ難易度の最終階でスライムキングを元の世界へ送り返し、異世界の門へ進むと、門を閉じるエンディングを経て完走です。途中で力尽きた場合も、到達階とスコアがその冒険の記録になります。2人のウサギKeeperが担架で運び始める短い演出のあと、結果画面へ進みます。

## 迷宮のものがたり

原因の分からないまま異世界の門が開き、生物たちが迷宮に迷い込んでしまいました。ミケロは肉球の力で、生物たちを元の世界へ送り返します。白い煙は帰還のしるし。慣れない場所で警戒する生物もいますが、スライムキングも含めて、帰る世界を持つ仲間です。

Keeperは、冒険者の手当てをしてくれるウサギたちの役割名です。各階の入口付近に1人いて、ミケロが力尽きたときには2人が迎えに来ます。

最終目的は、迷宮の奥で門を閉じ、新たな迷い込みを止めることです。門が開いた原因は不明のままとします。

## ダウンロードと起動

1. [リリースページ](https://github.com/kanon-ai/MIKERO-ODYSSEY/releases/tag/v1.6.1-test)から、Windows用ZIPまたはROM単体をダウンロードします。
2. Windows用ZIPはフォルダーごと展開し、`START.cmd` をダブルクリックします。
3. タイトルの **左右** で難易度を選び、**SPACE** または **ジョイスティックのボタン1** で開始します。

Windows用ランチャーには、別途 **openMSXとC-BIOS** が必要です。エミュレーターやBIOSは同梱していません。このリポジトリを取得した場合は `game/START.cmd` から起動できます。

旧版の途中状態を復元するとキークリック無効化が反映されないため、新しいROMは最初から起動してください。

他のMSXエミュレーターでは、`MIKERO-ODYSSEY.rom` を **ASCII16** として読み込んでください。

<details>
<summary>openMSXを標準以外の場所に置いている場合</summary>

`OPENMSX_EXE` に `openmsx.exe` のパス、必要に応じて `OPENMSX_SYSTEM_DATA` にopenMSXの `share` フォルダーを指定してください。ランチャーは外部のC-BIOSを参照して、MSX1・RAM32KBの起動設定を作成します。

</details>

## 操作方法

| 操作 | キーボード | ジョイスティック |
|---|---|---|
| 難易度選択（タイトル） | 左右 | 左右 |
| 移動 | 矢印キー | 方向入力 |
| 隣の敵を攻撃 | 敵のいる方向へ入力 | 同左 |
| その場で待機 | SPACE | ボタン1 |
| 手持ちの回復薬を使う | Z | ボタン2 |
| ゲーム開始・結果画面から同じ難易度で再挑戦 | SPACE | ボタン1 |
| 結果画面からタイトルへ | X | キーボードのX |
| Keeperに回復してもらう | 隣接してKeeperのいる方向へ入力 | 同左 |

**Keeperの手当ては、EASYでは金貨5枚で全回復、NORMALでは金貨15枚でHP24回復・各階1回です。** HPが減っていて、必要な金貨があると利用できます。各階の入口付近に1人います。ZキーはKeeperとの会話ではなく、手持ちの回復薬を使う操作です。

壁にぶつかった場合や、薬がない・HPが満タンで回復薬を使えない場合はターンを消費しません。Keeperとのやり取りもターンを消費しません。

## 画面の見方

| 表示 | 意味 |
|---|---|
| F | 現在の階層 |
| LV | ミケロのレベル |
| G | 所持金貨 |
| HP | 冒険を続ける体力。現在HP／最大HP |
| POT | 手持ちの回復薬の数 |
| FOOD | 残りの食料 |
| 右上の三角 | 階段のおおよその方角。最終階では門の方角 |
| 下から2行目 | 拾った物や戦闘などのメッセージ |
| 最下段 | 移動・待機・回復のキー説明 |

見えた場所は探索済みとして残りますが、壁の向こうにあるアイテムや敵は見通せません。三角を目安に進みつつ、脇道のアイテムを取りに行くか判断します。

## 戦闘・アイテム・回復

生物に隣接してその方向へ入力すると、肉球で攻撃します。送り返すまでに何度か必要な相手もいます。攻撃後は相手も行動するので、HPと回復薬の残数を見ながら進みましょう。元の世界へ帰るときは白い煙になって退場し、経験値・金貨・スコアが得られます。レベルアップすると最大HPと攻撃力が上がります。EASYは全回復、NORMALはHP6回復です。NORMALのキングには強い接触の予兆があり、一歩離れてかわす選択ができます。

| 見つけるもの | 効果 |
|---|---|
| 回復薬 | POTが1個増えます。Z／ボタン2で1個消費し、EASYではHP16、NORMALではHP12回復します（最大HPまで） |
| 魚 | FOODが100増えます |
| 金貨 | 所持金貨が5枚増え、25点を獲得します |
| 宝箱 | 金貨10枚と回復薬1個、100点を獲得します |
| 階段 | 次の階へ進みます |
| 異世界の門 | 最終階のスライムキングを送り返したあとに進むと完走です |

食料はターンごとに減ります。食料がある間は一定の行動ごとにHPが自然回復し、食料が尽きると行動するたびにHPが減ります。回復薬を使う操作でもターンが進み、敵が行動する点に注意してください。2マス先の生物へ踏み込む前にSPACEで近づいてくるのを待つと、先手を取りやすくなります。隣での待機は相手にも行動させます。

開始時は **EASYがHP24・回復薬3個・食料400、NORMALがHP24・回復薬2個・食料300**。まずは入口付近の薬や宝箱、魚を確認し、右上の三角を頼りに階段へ向かってみてください。

## 難易度と補給

| 項目 | EASY：子供向け | NORMAL：大人向け・高難度 |
|---|---|---|
| 深さ | 15階 | 30階 |
| 最初の回復薬／所持上限 | 3個／9個 | 2個／5個 |
| 1個の回復量 | HP16 | HP12 |
| 1階の回復薬 | 薬6個＋宝箱3個 | 薬4個＋宝箱1個 |
| 1階の魚 | 15個 | 3個 |
| レベルアップ | 最大HP・攻撃力上昇、全回復 | 最大HP・攻撃力上昇、HP6回復 |
| Keeper | 金貨5枚で全回復、繰り返し可 | 金貨15枚でHP24回復、各階1回 |
| 食料がある間の自然回復 | 14行動ごとにHP1 | 28行動ごとにHP1 |

薬が満杯ならその場に残ります。満杯で開けた宝箱も薬を残し、金貨と点数だけ受け取れます。

## スコアと冒険の記録

| 出来事 | 得点 |
|---|---:|
| 次の階へ到達 | 200点 |
| 金貨を拾う | 25点 |
| 宝箱を開ける | 100点 |
| 通常の生物を送り返す | 種類に応じて20〜50点 |
| スライムキングを送り返す | 200点 |
| 門を閉じて完走 | EASYは追加1,500点、NORMALは追加3,000点 |

結果画面には今回のスコア・到達階と、難易度別のハイスコア・その記録の到達階を表示します。同点の場合は、より深い階まで進んだ記録を優先します。スコアの上限は65,535点です。

**ハイスコアは再挑戦・難易度切り替えをまたいで保持し、ROM単体では電源OFFで消えます。** WindowsのopenMSXでは標準キーの **Alt＋F8で状態保存、Alt＋F7で復元** が使えます。終了後も同じ起動フォルダーから再開できます。これはエミュレーターの機能で、ROMの実機用セーブ機能ではありません。

## 動作環境とビルド方法

| 項目 | 仕様 |
|---|---|
| 対象 | 初代MSX（MSX1） |
| ROM | 512 KiB・ASCII16マッパー |
| メインRAM | 32 KiB |
| VRAM | 16 KiB |
| 描画 | 2×2文字のPCGブロック、スプライトによる色と演出の補助 |
| 音源 | PSG・音楽2声＋効果音1声 |

Python 3と、`sdasz80` を含むSDCCを用意してください。SDCCをPATHに追加するか、`SDCC_BIN` にその `bin` ディレクトリを設定します。

```console
python work/source/build.py
```

`outputs/MIKERO-ODYSSEY.rom` が生成されます。グラフィックと地形データも同梱のPythonソースから生成します。

## 高速化

同条件のopenMSX比較では、描画時間の中央値が約157msから80msへ短縮し、長押し移動は約2.3〜2.6倍になりました。8ドットずつ2回のスクロールは維持しています。数値はエミュレーター上の測定で、実機測定値ではありません。
