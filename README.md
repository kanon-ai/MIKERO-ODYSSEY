# MIKERO-ODYSSEY

A 30-floor, turn-based cat dungeon adventure for the original MSX.

猫のミケロで地下30階に挑む、スコアトライアル型のローグゲームです。限られた視界を頼りに道を探し、迷い込んだ生物を肉球でポンと元の世界へ送り返しながら、どこまで潜れるかに挑戦します。

現在の公開版は **v1.5.6-test**。世界観に合わせてメッセージと説明文を調整しました。ゲームバランスは調整中です。

## どんなゲーム？

- **行動するたびに時間が進むローグゲーム。** 移動・攻撃・待機・回復薬で1ターン進みます。入力を待つ間、敵の行動と空腹の進行は止まります。
- **ミケロを中心に周囲がスクロール。** 1マスは16×16ドット。移動表示を8ドットずつ2回に分け、15×9マスの範囲を見渡せます。
- **階段の方角が分かる三角マーカー。** 未探索でも右上に大まかな方向を表示します。壁を避けた道順ではないので、通路を探しながら進みます。
- **階ごとに変わる色と雰囲気。** 黒い床を基調に、壁やキャラクターが色鮮やかにアニメーションします。8種類のテーマが30階を彩ります。
- **行動に合わせて進む2声の音楽。** ひと区切りずつ鳴り、手を止めると短い余韻のあと静かになります。64行動分の旋律を巡ります。

30階のスライムキングを元の世界へ送り返し、王冠を取ると完走です。途中で力尽きた場合も、到達階とスコアがその冒険の記録になります。2人のウサギKeeperが担架で運び始める短い演出のあと、結果画面へ進みます。

## 迷宮のものがたり

原因の分からないまま異世界の門が開き、生物たちが迷宮に迷い込んでしまいました。ミケロは肉球の力で、生物たちを元の世界へ送り返します。白い煙は帰還のしるし。慣れない場所で警戒する生物もいますが、スライムキングも含めて、帰る世界を持つ仲間です。

Keeperは、冒険者の手当てをしてくれるウサギたちの役割名です。各階の入口付近に1人いて、ミケロが力尽きたときには2人が迎えに来ます。

**今後のラストは「迷宮の奥にある門を閉じる」冒険へつなげる予定です。門を閉じる処理・演出はまだ実装しておらず、現行版の完走条件は30階の王冠です。** 門が開いた原因は不明のままとします。

## ダウンロードと起動

1. [リリースページ](https://github.com/kanon-ai/MIKERO-ODYSSEY/releases/tag/v1.5.6-test)から、Windows用ZIPまたはROM単体をダウンロードします。
2. Windows用ZIPはフォルダーごと展開し、`START.cmd` をダブルクリックします。
3. タイトル画面で **SPACE** または **ジョイスティックのボタン1** を押すと開始します。

Windows用ランチャーには、別途 **openMSXとC-BIOS** が必要です。エミュレーターやBIOSは同梱していません。このリポジトリを取得した場合は `game/START.cmd` から起動できます。

他のMSXエミュレーターでは、`MIKERO-ODYSSEY.rom` を **ASCII16** として読み込んでください。

<details>
<summary>openMSXを標準以外の場所に置いている場合</summary>

`OPENMSX_EXE` に `openmsx.exe` のパス、必要に応じて `OPENMSX_SYSTEM_DATA` にopenMSXの `share` フォルダーを指定してください。ランチャーは外部のC-BIOSを参照して、MSX1・RAM32KBの起動設定を作成します。

</details>

## 操作方法

| 操作 | キーボード | ジョイスティック |
|---|---|---|
| 移動 | 矢印キー | 方向入力 |
| 隣の敵を攻撃 | 敵のいる方向へ入力 | 同左 |
| その場で待機 | SPACE | ボタン1 |
| 手持ちの回復薬を使う | Z | ボタン2 |
| ゲーム開始・結果画面から再挑戦 | SPACE | ボタン1 |
| Keeperに回復してもらう | 隣接してKeeperのいる方向へ入力 | 同左 |

**Keeperの回復は金貨5枚で全回復。** HPが減っていて、金貨が5枚以上あると利用できます。各階の入口付近に1人います。ZキーはKeeperとの会話ではなく、手持ちの回復薬を使う操作です。

壁にぶつかった場合や、薬がない・HPが満タンで回復薬を使えない場合はターンを消費しません。Keeperとのやり取りもターンを消費しません。

## 画面の見方

| 表示 | 意味 |
|---|---|
| F | 現在の階層 |
| LV | ミケロのレベル |
| G | 所持金貨 |
| HP | 冒険を続ける体力。現在HP／最大HP |
| POT | 手持ちの回復薬の数 |
| FOOD | 残りの食料 |
| 右上の三角 | 階段のおおよその方角。30階では王冠の方角 |
| 下から2行目 | 拾った物や戦闘などのメッセージ |
| 最下段 | 移動・待機・回復のキー説明 |

見えた場所は探索済みとして残りますが、壁の向こうにあるアイテムや敵は見通せません。三角を目安に進みつつ、脇道のアイテムを取りに行くか判断します。

## 戦闘・アイテム・回復

生物に隣接してその方向へ入力すると、肉球で攻撃します。送り返すまでに何度か必要な相手もいます。攻撃後は相手も行動するので、HPと回復薬の残数を見ながら進みましょう。元の世界へ帰るときは白い煙になって退場し、経験値・金貨・スコアが得られます。レベルアップすると最大HPと攻撃力が上がり、HPが全回復します。

| 見つけるもの | 効果 |
|---|---|
| 回復薬 | POTが1個増えます。Z／ボタン2で1個消費し、HPを16回復します（最大HPまで） |
| 魚 | FOODが100増えます |
| 金貨 | 所持金貨が5枚増え、25点を獲得します |
| 宝箱 | 金貨10枚と回復薬1個、100点を獲得します |
| 階段 | 次の階へ進みます |
| 王冠 | 30階のスライムキングを送り返したあとに取ると完走です |

食料はターンごとに減ります。食料がある間は一定の行動ごとにHPが自然回復し、食料が尽きると行動するたびにHPが減ります。回復薬を使う操作でもターンが進み、敵が行動する点に注意してください。

開始時は **HP24・回復薬3個・食料400**。まずは入口付近の薬や宝箱、魚を確認し、右上の三角を頼りに階段へ向かってみてください。

## スコアと冒険の記録

| 出来事 | 得点 |
|---|---:|
| 次の階へ到達 | 200点 |
| 金貨を拾う | 25点 |
| 宝箱を開ける | 100点 |
| 通常の生物を送り返す | 種類に応じて20〜50点 |
| スライムキングを送り返す | 200点 |
| 30階の王冠を取って完走 | 追加3,000点 |

結果画面には今回のスコア・到達階と、ハイスコア・その記録の到達階を表示します。同点の場合は、より深い階まで進んだ記録を優先します。スコアの上限は65,535点です。

**ハイスコアはSPACEでの再挑戦をまたいで保持しますが、電源OFFやエミュレーター終了で消えます。** 冒険の途中セーブ機能はありません。

## 動作環境とビルド方法

| 項目 | 仕様 |
|---|---|
| 対象 | 初代MSX（MSX1） |
| ROM | 512 KiB・ASCII16マッパー |
| メインRAM | 32 KiB |
| VRAM | 16 KiB |
| 描画 | 2×2文字のPCGブロック、スプライトによる色と演出の補助 |
| 音源 | PSG・音楽2声＋効果音1声 |

Python 3と、`sdasz80` を含むSDCCを用意してください。SDCCをPATHに追加するか、`SDCC_BIN` にその `bin` ディレクトリを設定します。

```console
python work/source/build.py
```

`outputs/MIKERO-ODYSSEY.rom` が生成されます。グラフィックと地形データも同梱のPythonソースから生成します。
