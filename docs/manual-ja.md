# MIKERO-ODYSSEY v1.6.1 テスト版

異世界から迷宮に迷い込んだ生物を、猫のミケロが肉球で元の世界へ送り返す冒険です。最奥のスライムキングを送り返し、門へ進むと、異世界の門を閉じるエンディングになります。門が開いた原因は不明のままです。

## 起動・操作

試遊用の MIKERO-ODYSSEY.zip をフォルダーごと展開して START.cmd をダブルクリックしてください。ソースZIPを使用する場合は末尾のビルド手順を参照してください。外部のopenMSXとC-BIOSが必要です。エミュレーター、BIOSは同梱しません。他のエミュレーターではROMをASCII16として読み込みます。

MSX1・メインRAM32KB・VRAM16KB、512KB ASCII16 ROM。実機では未検証です。

| 場面・操作 | キーボード | ジョイスティック |
|---|---|---|
| タイトルで難易度選択 | 左右 | 左右 |
| 開始・結果画面から同じ難易度で再挑戦 | SPACE | ボタン1 |
| 結果画面からタイトルへ | X | キーボードのX |
| 移動・隣の生物へ肉球 | 矢印 | 方向入力 |
| その場で待機 | SPACE | ボタン1 |
| 回復薬 | Z | ボタン2 |
| Keeperの手当て | 隣からKeeperの方向へ入力 | 同左 |

右上の三角は階段のおおよその方角です。最終階では門を指します。壁を避ける道順ではありません。最下段には移動・待機・回復のキー説明が残ります。

## 難易度

| 項目 | EASY：子供向け | NORMAL：大人向け・高難度 |
|---|---|---|
| 深さ | 15階 | 30階 |
| 最初の回復薬／所持上限 | 3個／9個 | 2個／5個 |
| 1個の回復量 | HP16 | HP12 |
| 1階の回復薬 | 薬6個＋宝箱3個 | 薬4個＋宝箱1個 |
| 1階の魚 | 15個 | 3個 |
| レベルアップ | 最大HP・攻撃力上昇、全回復 | 最大HP・攻撃力上昇、HP6回復 |
| Keeper | 金貨5枚で全回復、繰り返し可 | 金貨15枚でHP24回復、各階1回 |
| 食料がある間の自然回復 | 14行動ごとにHP1 | 28行動ごとにHP1 |

EASYは以前の薬21個相当／階から9個相当へ減らし、レベルアップとKeeperの全回復を残しました。NORMALは補給、残りHP、相手に囲まれない位置取りが大切です。最終階のキングは息を吸う予兆の次の行動で強くぶつかってきます。予兆を見たら一歩離れる選択ができます。

薬が満杯の場合、薬はその場に残ります。満杯で宝箱を開けた場合も、中の薬を残して金貨と点数だけ受け取れます。同じ箱から繰り返し点数は得られません。魚は食料100、金貨は5枚と25点、宝箱は金貨10枚と薬1個と100点です。

2マス先の生物へ踏み込むと、こちらが肉球を出す前にぶつかられることがあります。SPACEで近づいてくるのを待ってから肉球を使うと、先手を取りやすくなります。すでに隣にいるときの待機は、相手にも行動させます。囲まれそうなら、通路で一体ずつ向き合う位置取りも大切です。NORMALでもレベルアップにより、軽い相手を一度で送り返せる場面を残しています。

力尽きると2人のウサギKeeperが担架で迎えに来ます。結果画面には到達階、スコアと難易度別の最高記録を表示します。記録は再挑戦・難易度切り替えをまたいで保持し、ROM単体では電源OFFで消えます。

## 中断して後日続ける（WindowsのopenMSX）

標準キーの **Alt＋F8で状態保存、Alt＋F7で復元** が使えます。保存後は終了して構いません。同じフォルダーのSTART.cmdから起動して復元してください。保存先はランチャー用の play/savestates です。保存すると同じスロットを上書きします。

これはエミュレーターの機能で、ROMの実機用セーブ機能ではありません。ROMを更新する際は、旧版フォルダーと保存状態を残してください。別バージョンへの保存状態の移行は保証しません。

## 今回の変更と検証

描画処理、表示数値の変換、長押し入力の待ち時間、静止した床の不要な転送を見直しました。16ドット移動を8ドットずつ2回で表示するスクロールは維持しています。同条件のopenMSX測定では、描画時間の中央値が約157msから80ms、連続移動が約2.3～2.6倍になりました。これはエミュレーター上の比較で、実機測定値ではありません。

門を閉じる演出を追加し、エンディングの顔もタイトルと同じPCG＋スプライトの顔にそろえました。NTSC/PALでスクロール、方位表示、担架、難易度別記録、アイテム、門の演出を確認しています。個別の結果は同梱の検証JSONを参照してください。全マップを参照する自動操作で、EASY15階とNORMAL30階の完走を確認しました。NORMALは待機で先手を取り、キングの予兆をかわす操作での完走例です。自動プレイの結果は人が感じる難易度の保証ではありません。

BGMは、行動のたびに2声のフレーズが進み、止まると短い余韻のあと静かになる方式を維持しています。64行動の旋律も変更していません。P. I. Tchaikovsky『くるみ割り人形・行進曲』をもとにした独自PSG編曲・変奏です。
[参照楽譜](https://imslp.org/wiki/The_Nutcracker_(suite),_Op.71a_(Tchaikovsky,_Pyotr))

gameplay.gif はこの版のROMを普通に操作した約14秒のネイティブ映像です。再生時間を実際のエミュレーション時間に合わせています。GIFは無音です。

## ビルド

Python 3とSDCCを用意し、SDCCをPATHに追加するかSDCC_BINを指定して、ソースZIP内の `python work/source/build.py` を実行します。エミュレーター検証には外部openMSX、C-BIOS、Pillowが必要です。OPENMSX_EXEとOPENMSX_SYSTEM_DATAで外部環境を指定できます。

旧版との比較を行う検証では、v1.5.6-testのソースを別フォルダーでビルドし、そのルートを MIKERO_BASELINE_ROOT に指定してください。比較用の旧ROMや外部BIOSはソースZIPには含めていません。


v1.6.1ではキークリック音を起動時にOFFにしました。旧版の途中状態ではなく、新しいROMを最初から起動してください。
