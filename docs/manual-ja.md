# MIKERO-ODYSSEY — 30階トライアル

START.cmdをダブルクリックして起動します。既存のopenMSXとC-BIOSを利用します。初代MSX、RAM32KB、VRAM16KB、512KB ASCII16 ROMです。

## 遊び方

カーソル／ジョイスティック：移動・隣の敵へ肉球攻撃。SPACE／ボタン1：開始・待機・再挑戦。Z／ボタン2：回復薬。
30階のスライムキングを倒し、王冠を取ると完走です。HPがなくなった時も記録画面を表示します。
白いウサギのKeeperは金5枚で全回復。薬はHP16、魚はFOOD100回復。空腹・戦闘の基本ルールは前版を引き継いでいます。

## 歩くメロディ

『くるみ割り人形』より「行進曲」冒頭4小節の上声を、PSGの単音に打ち込みました。19音で一巡します。1歩につき1音で、リズムは歩く間隔に従います。曲全体の連続演奏ではありません。
止まると短く減衰します。壁・その場の攻撃・待機では曲は進みません。効果音とは別のPSGチャンネルを使用し、効果音が鳴っている間はメロディの音量を抑えます。再挑戦で曲の先頭に戻ります。
音源：チャイコフスキー自身のピアノ版、Jurgenson 1892／Rahter 1898年頃の再版、8ページ。既存の録音や現代の編曲は使用していません。
[楽譜とPublic Domain表記](https://imslp.org/wiki/The_Nutcracker_(suite),_Op.71a_(Tchaikovsky,_Pyotr))
[参照した楽譜](https://s9.imslp.org/files/imglnks/usimg/f/f1/IMSLP57454-PMLP03607-Tchaikovsky_op71_Nutcracker_%28pf%29.pdf)

## スコア

- 次の階へ到達：200点
- 金貨：25点、宝箱：100点
- 敵：スライム20点、ひよこ30点、キノコ40点、雲の精50点
- スライムキング：200点
- 30階完走：追加3000点

上限65535点で止まり、桁あふれしません。結果画面は今回のスコア・到達階・ハイスコア・ハイスコアを出した回の到達階を表示します。同点なら深い階を優先します。
ハイスコアはSPACEでの再挑戦をまたいで保持します。電源OFF、ROM再読み込み、エミュレーター終了で消えます。永続セーブはありません。

## 検証

検証JSONにROMのSHA-256と実行結果を記録しています。キー入力だけの通しプレイは1526操作で14階・6800点の途中終了を確認しました。30階通しクリアは未確認です。検証用階段による全30階の読み込みと、最終階の完走処理は別に確認しています。スコア・消音・記録保持のシナリオは検証用RAMを設定し、実際のキー入力とPSGレジスターで確認しています。
歩行メロディのWAVはエミュレーターで実ROMを動かして録音したものです。実機と物理スピーカーでの確認はしていません。

## 再ビルド

ソースZIPを展開し、Python 3とSDCCを用意して `python work/source/build.py` を実行します。必要ならSDCC_BINを指定してください。配布ソースからの再ビルドが同一ROMになることを検証しています。
