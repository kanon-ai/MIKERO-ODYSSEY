# MIKERO-ODYSSEY v1.5.6 テスト版

迷宮に迷い込んだ異世界の生物を、ミケロが肉球の力で元の世界へ送り返す冒険です。白い煙は帰還のしるし。Keeperは冒険者の手当てをするウサギたちで、各階の入口付近に1人います。力尽きたミケロは2人のKeeperが担架で迎えに来ます。

この版では、肉球、生物との接触、Keeperの回復などのメッセージを世界観に合わせました。担架場面の追加説明を省き、運び始めたところで結果画面へ移ります。

最終的に異世界の門を閉じるラストを予定していますが、その処理・演出は未実装です。現在は30階のスライムキングを送り返し、王冠を取ると完走します。門が開いた原因は不明です。

右上の黄色い三角マーカーは階段のおおよその方向を8方向で示します。未発見でも表示され、最終30階では王冠を指します。壁を避けた道順ではありません。

START.cmdをダブルクリックして起動してください。外部openMSXとC-BIOSを使用します。MSX1・RAM32KB・VRAM16KB・512KB ASCII16 ROMです。

矢印：移動／肉球攻撃、SPACE：開始・待機・再挑戦、Z：回復薬。ジョイスティックのボタン1は待機、ボタン2は回復です。Keeperの隣から、その方向へ入力すると金貨5枚で全回復します。ハイスコアは再挑戦をまたいで保持し、電源OFFで消えます。

NTSC/PALでメッセージと担架演出、8方向マーカー、階層移動時の目標更新、最下段のキー説明、スクロールを検証しました。回復・アイテム・完走・再挑戦もエミュレーターの条件を設定した場面で確認しています。実機試験と30階通しのゲームバランス評価は未実施です。

BGMはP. I. Tchaikovsky『くるみ割り人形・行進曲』をもとにした独自PSG編曲・変奏です。
[参照楽譜](https://imslp.org/wiki/The_Nutcracker_(suite),_Op.71a_(Tchaikovsky,_Pyotr))

ビルドにはPython 3とSDCCが必要です。SDCCをPATHに追加するかSDCC_BINを設定し、python work/source/build.pyを実行します。検証にはPillow、外部openMSXとC-BIOSが必要です。
