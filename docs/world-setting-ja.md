# MIKERO-ODYSSEY 世界観・制作方針

2026年9月13日、ユーザーとの合意に基づく今後の制作基準。

## 冒険の設定

何かの拍子に異世界の門が開き、異世界の生物が迷宮に迷い込んだ。ミケロは、その生物たちを肉球の力で元の世界へ送り返しながら、門を閉じるために迷宮の奥へ進む。

戦闘の決着は相手の死ではなく、元の世界への帰還として扱う。迷宮で出会う生物は、必ずしも悪意を持った存在ではない。

## 登場する生物とKeeper

迷い込んだ生物は、慣れない場所で戸惑ったり警戒したりしている。ミケロに近づく、ぶつかる、身を守ろうとする行動で冒険の緊張感を表す。帰還させるまでに何度か肉球を使う場合も、傷つけることを見せ場にはしない。

スライムキングも元の世界へ帰る生物の一員。門を開いた犯人や、悪の支配者とは設定しない。

Keeperは迷宮で冒険者を手助けするウサギたちの役割名とする。各階の入口付近では1人が回復を手伝い、ミケロが力尽きたときには2人が担架で迎えに来る。各階に同じ1人が先回りしている、という説明は設けない。

## 今後のラスト設定

冒険の最終目的は、開いてしまった異世界の門を閉じること。生物を元の世界へ送り返す道中の行動と、最奥へ向かう目的をつなげる。

門が開いた原因は不明とする。後で原因を明かすことを前提とせず、原因となる人物や悪役を設ける必要もない。門の姿、閉じ方、最後の相手との関係、エンディングの演出は未定とする。

ラストを具体化するときは、門を閉じたことで残った生物が帰れなくなるような描写を避ける。全ての階の生物を探し尽くす作業を、完走の必須条件にはしない。

今後この設定をラストへ反映する。現行版の30階・スライムキング・王冠による完走処理は、今回の設定追加だけでは変更しない。

## 表現の基準

- 肉球の「ぽん」というアクションを、送り返す演出につなげる。白い煙は消滅や死ではなく、帰還の表現とする。
- 通常の生物も大型の相手も、この世界観に合わせる。素朴で親しみやすい姿を保ち、醜悪さや恐怖を主な魅力にしない。
- ミケロが力尽きた際は、左右のウサギKeeperが担架で運び始める短い演出を挟み、結果画面へ進む。
- 設定をゲーム中の文章で説明しすぎない。肉球・煙・担架などの描写と、遊ぶ人の想像を大切にする。「MIKERO IS SAFE!」は再表示しない。
- HPは冒険を続ける体力として扱い、ゼロになったら救出へつなげる。回復は手当てとして伝え、未設定の「命の光」などの説明を加えない。
- 孫が遊んでいる様子を見守る人にも、出来事を理解しやすい表現を目指す。

## ゲームとの関係

冒険の緊張感や仕掛けの駆け引きは、この世界観の中で作る。全30階の到達記録とスコアを目指すトライアル形式を維持する。仲間を救出して地上へ連れ帰る往復型の目的には置き換えない。

得点は探索、発見、生物の帰還による冒険の記録として伝える。「攻撃」「戦闘」など操作を理解するための用語は使えるが、「討伐」「殺害」を目的やごほうびの説明には用いない。

大きく動くPCGの仕掛けでは、動きの予兆や退避場所が画面から分かることを大切にする。止まって考えられるローグの感覚に合わせ、危険の進行は原則として行動単位で考える。巨大な球や隠れるくぼみなど、個々の仕掛けは引き続き検討案とする。

今回の合意は世界観の基準であり、戦闘・回復・得点の数値や、未決定の仕掛けを変更・採用する指示ではない。今後のキャラクター、演出、物語、公開用説明文を制作するときに本書と照合する。
